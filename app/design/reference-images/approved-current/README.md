# Références visuelles JTransport — approuvées par le client

Ces cinq captures sont des références fonctionnelles et visuelles à suivre pour l'implémentation de JTransport.

1. `IMG_3949.jpeg` — accueil / tableau de bord particulier avec missions recommandées, publication, recherche, messagerie, paiements et profil.
2. `IMG_3948.jpeg` — liste des missions disponibles avec filtres par mode de transport.
3. `IMG_3947.jpeg` — détail d'une mission, disponibilité, prix, description et action « Faire une offre ».
4. `IMG_3946.jpeg` — formulaire de publication d'une mission, étapes marchandise/transport/récapitulatif.
5. `IMG_3945.jpeg` — profil prestataire/transporteur avec présentation, véhicules, avis et boutons Contacter/Appeler.

## Consigne d'implémentation

Les images sont des références UX/UI et non des écrans statiques à copier comme simple maquette. Chaque élément interactif visible doit être relié à une vraie route, un vrai état, une API et une persistance backend lorsque nécessaire.

Les captures doivent être utilisées conjointement avec le cahier des charges maître. Elles ne doivent pas introduire de catégories étrangères au transport/logistique (mode, vêtements, téléphones, alimentation, etc.).
