# JTransport — Master Final Unique

Ce package regroupe les travaux JTransport réalisés précédemment dans un seul projet.

## Source de vérité
Lire en premier : `CAHIER_DES_CHARGES_JTRANSPORT_FINAL_UNIQUE.md`

## Code
- `app/web/` : socle web Next.js/TypeScript
- `app/mobile/` : socle mobile Expo/React Native/TypeScript
- `app/backend/` : notes de démarrage backend
- `app/specs/` : contrats JSON techniques

## Design
Les références conservées sont exclusivement JTransport/transport/logistique.

## Règle
Le socle fourni n'est pas considéré comme une application production terminée. Claude doit implémenter le backend, la base de données, l'authentification, les permissions, les API, les paiements, le tracking, les documents, la douane, les contrats, la facturation, la messagerie, le dispatch, les tests et les intégrations conformément au cahier maître.

## Références visuelles approuvées

Les références les plus récentes fournies par le client sont dans `app/design/reference-images/approved-current/`. Elles couvrent l'accueil, les missions, le détail mission, la publication et le profil transporteur. Elles servent de référence UX/UI et toutes les actions doivent être fonctionnelles, pas seulement graphiques.
